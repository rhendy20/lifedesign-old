# /eval — harness, personas, rubric, results

## Pieces

| Path | What |
|---|---|
| `personas/` | 10 synthetic personas. `experiences/` is all the engine sees; `ground_truth.json` + `persona.json` are judge-only. Generated by `generate_personas.py` in a context that never sees the engine prompts. |
| `sealed/` | Where Robert's sealed files A/B/C go. Empty this run. |
| `rubric.md` | Depth rubric and the three deciding numbers. |
| `harness/run_eval.py` | Run one (generation, tier) over all personas; freezes outputs with hashes + timestamps. |
| `harness/score.py` | Blind judge: pools all listed conditions per persona, strips labels, shuffles, scores in one call against ground truth. |
| `harness/report.py` | Aggregates depth rate, hit recall, hit share, FP rate, grounding, $/experience, s/experience; per-archetype table. |
| `harness/catalogue.py` | Turns a condition's scored outputs into a failure catalogue (v0's becomes the v2 critic checklist). |
| `results/outputs/<gen>__<tier>/` | Frozen engine outputs per persona + `FROZEN.json`. |
| `results/scores/` | Judge scores per persona per score-set. |
| `results/ledger.jsonl` | Every model call: model, tokens, cost (CLI list-price basis), latency, tag. |
| `results/summary.md` | The numbers. |

## Typical sequence

```bash
python3 eval/harness/run_eval.py --gen v0 --tier mid
python3 eval/harness/run_eval.py --gen v1 --tier mid
python3 eval/harness/score.py --conditions v0__mid v1__mid        # blind, pooled
python3 eval/harness/report.py --tag <tag printed by score.py>
python3 eval/harness/catalogue.py --condition v0__mid --tag <tag>
```

Engine stages run with extended thinking off (`MAX_THINKING_TOKENS=0`) so prompts, not thinking budget, are what is measured.
The judge (Opus 5) runs with a 6k thinking budget.

| p10_freshman | young_thin_corpus | 19, four short recent experiences; thin corpus |

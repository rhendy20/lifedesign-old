# Global AGENTS.md — Robert's Working Agreements

## Who I Am

I'm Robert, a non-technical founder building an AI-powered life design platform. I use AI coding tools as my technical co-founder. I am my own ideal customer.

## How to Work With Me

- Be direct. Skip unnecessary preamble.
- Push back when something doesn't make sense technically or product-wise.
- Propose alternatives, don't just flag problems.
- Think in systems, not isolated features.
- When scope is unclear, ask clarifying questions — don't silently guess.
- Build the smallest useful version first. I iterate fast.

## Universal Standards

- Write clean, readable code with clear naming.
- Comment the "why," not the "what."
- Handle errors gracefully — never leave the user in a broken state.
- Protect user data. Default to the cautious approach.
- Run tests before committing. Fix failures before submitting PRs.
- Keep PRs focused — one concern per PR when possible.

## PR Descriptions

Keep them direct:

- **What:** 1-2 sentences on what changed
- **Why:** The product or technical reason
- **How:** Brief approach if non-obvious
- **Testing:** What was verified

## When Uncertain

State your assumptions explicitly. Tell me what you're unsure about. I'd rather see "I assumed X because Y — let me know if that's wrong" than a silent guess that sends things in the wrong direction.
